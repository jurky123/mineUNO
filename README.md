# MineUNO

一个运行在 Paper 26.2 上的 3D UNO 小游戏插件：玩家围坐在真实的牌桌旁，用手里的实体牌出牌、摸牌、喊 UNO。附赠一个通用的材质包托管插件 **PackHost**。

- 2 ~ 8 人同桌，完整经典 UNO 规则
- 3D 实体牌桌：桌面、牌堆、弃牌堆、发牌与出牌动画
- 手牌是悬浮在面前的实体牌，准星选牌、左键出牌
- 内置大厅、房间、规则教程界面，多桌可同时进行

---

## 玩法规则

- 经典 108 张牌：红/黄/绿/蓝四色，0~9 各两张，跳过/反转/+2 各两张，万能牌与万能 +4 各四张
- 开局每人 7 张，翻一张起始牌，随机决定先手
- 出牌条件：与上一张牌**颜色相同**、**数字/功能相同**，或打出万能牌
- **+2**：下家摸 2 张并跳过（默认不可叠加）
- **跳过**：跳过下一位玩家
- **反转**：改变出牌方向；两人局时等同跳过，自己再出一张
- **万能牌**：任何时候可出，出后选择新颜色
- **万能 +4**：出后选色，下家摸 4 张并跳过；下家可选择**质疑**
  - 质疑成功（对方手里还有当前颜色）：对方摸 4 张，你正常出牌
  - 质疑失败（对方确实没有）：你摸 6 张并跳过
- **摸牌**：每回合只摸 1 张；摸完只能打出刚摸到的这张，或结束回合
- **UNO**：剩 2 张时可以提前喊；打出后剩 1 张即安全。忘记喊会被别人抓到罚摸 2 张（补喊也可以），窗口持续到下一位玩家行动为止
- 牌堆用完自动把弃牌堆洗回牌堆；最后一张是 +2 / +4 时先结算罚牌再分胜负

## 胜负模式

| 模式 | 规则 |
| --- | --- |
| Quick | 第一个出完手牌的人获胜，一局定胜负 |
| Classic 500 | 官方计分：数字牌=面值，跳过/反转/+2=20 分，万能牌=50 分；赢家获得其他人剩余手牌总分，先累计 500 分获胜，局间 10 秒自动开下一局 |

## 3D 牌桌

- 桌上摆着牌堆与弃牌堆；打出的牌会按随机位置和角度叠放（新牌永远在最上层），可以看清最近打出过哪些牌
- 发牌动画：开局逐轮把牌发到每个人面前
- 摸牌动画：牌背从牌堆一张一张飞进你的手牌
- 出牌动画：牌从你的手牌沿弧线飞到弃牌堆的实际落点
- 桌面中央常驻显示**当前生效颜色**与**出牌方向**，每位玩家面前显示剩余手牌数
- 座位为隐形坐姿：开局自动坐下，对局中不能走动，但可以自由转头观察牌桌

## 手牌操作

- 手牌是悬浮在你面前、**只有自己能看到**的实体牌，按颜色/数字自动排序
- 手牌多时自动分成上下两排，不会再有牌被挡住
- **准星指向某张牌**即选中：选中的牌会向外弹出并发光
- **左键**打出选中的牌；**右键**摸牌；**潜行 + 左键**结束回合
- 右键弃牌区（桌面右半边）打开**控制面板**：摸牌 / 结束回合 / 喊 UNO / 规则 / 离开牌局

## 提示与氛围

- 屏幕上方 BossBar：当前回合玩家、生效颜色、剩余时间、上一张打出的牌
- 回合开始时，标识会飞到该玩家头顶显示「▶ XX 的回合」，本人还会收到标题提示与音效
- 被跳过时标识会先飞到被跳过者头顶停留片刻，再移动到下一位，本人会收到「你被跳过」提示
- 发牌、出牌、摸牌、反转、Wild 选色、UNO、被抓、质疑、胜利都有对应音效与粒子（可在配置中关闭）

## 大厅与房间

- `/uno` 打开大厅：创建 Quick / Classic 房间，或加入已有房间
- 创建后自动准备，队友加入即同步显示；房主离开会自动转移房主
- 至少 2 人且全部准备即可开始；服务器可同时开多桌
- 内置 6 页规则与教程界面（大厅书页或 `/uno rules`）

## 超时与断线

- 回合超时自动摸一张并结束回合；选色超时自动选手中最多的颜色；质疑超时自动接受
- 断线保留座位与手牌 60 秒，重连自动回到牌桌；超时视为弃权，手牌洗回牌堆

## 命令

| 命令 | 说明 |
| --- | --- |
| `/uno` | 打开大厅 / 房间 / 控制面板（按当前状态自动切换） |
| `/uno create [quick\|classic]` | 创建房间 |
| `/uno join [编号]` | 加入房间 |
| `/uno ready` | 准备 / 取消准备 |
| `/uno start` | 开始游戏（房主） |
| `/uno leave` | 离开房间 / 对局中离开视为弃权 |
| `/uno hand` | 打开控制面板 |
| `/uno draw` / `/uno pass` | 摸牌 / 结束回合 |
| `/uno uno` | 喊 UNO |
| `/uno catch <玩家>` | 抓 UNO |
| `/uno rules` | 规则与教程 |
| `/uno list` | 查看房间列表 |
| `/uno setarena` | 站在当前位置设置牌桌位置（管理员） |
| `/uno handtune` | 滚轮实时微调手牌（管理员） |
| `/uno seat <数值>` | 调整坐姿高度（管理员） |
| `/uno reload` | 重载配置（管理员） |

所有命令与参数都支持 Tab 补全。

## 配置

`plugins/MineUNO/config.yml` 中可调整：回合/质疑/重连时长、竞技场坐标、桌面大小与高度、座位半径、手牌数量/距离/大小/角度、弃牌堆显示张数与散布、动画/粒子/音效开关等。管理员可用 `/uno handtune` 滚轮实时微调手牌参数。

## 材质包

插件自带**原创**卡牌贴图（不含任何官方素材）：四种颜色的数字牌与功能牌、万能牌、卡背、桌面、颜色与方向指示。材质包通过 **PackHost** 下发给客户端，无需安装任何客户端 Mod。

## PackHost（附赠）

通用的材质包托管插件：

- 把任意数量的资源包 zip 放进 `plugins/PackHost/packs/`，自动合并成一个包
- 通过内置 HTTP 服务把材质包下发给客户端，玩家进服自动推送
- 命令：`/packhost reload` / `url` / `status` / `send <玩家>`

## 安装

1. 将 `MineUNO-*.jar` 与 `PackHost-*.jar` 放入服务器的 `plugins/` 目录
2. 将材质包 zip 放入 `plugins/PackHost/packs/`（本仓库可用 `pack/gen_pack.py` 重新生成）
3. 修改 `plugins/PackHost/config.yml`：设置端口与公网地址，并在防火墙放行该端口
4. 进游戏站在想要的位置执行 `/uno setarena` 设置牌桌

## 构建

```bash
./build.sh          # 产物输出到 out/：两个插件 jar + 材质包
```

要求 Java 25 与 Maven。
